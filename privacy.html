Privacy policy

Effective 9 October 2026. Applies to the ORVYQ upload tool (Google Cloud project orvyq-automation) and to this website.

Who uses the tool

The tool is used only by the owner of the ORVYQ YouTube channel, to manage that channel's own videos. It is not a public service, and it does not collect information about other people, viewers or subscribers.

Google data the tool accesses

Permission (scope)What it is used for
youtube.uploadUploading the channel's own videos and setting their custom thumbnails.
youtube.readonlyReading the connected channel's ID, name and handle, so that videos only go to the ORVYQ channel; reading back an uploaded video's status, title, description and thumbnail to check that it was saved correctly.
youtube.force-sslEditing the description of a video the channel has already uploaded. Although this permission also allows deleting videos, the tool has no delete function, and nothing is deleted without the channel owner's separate, explicit approval.

The tool does not read comments, messages, viewer or subscriber data, analytics, revenue, or any other Google account data.

What is stored, and where

  • Sign-in tokens (the access and refresh tokens Google issues). Stored only on the owner's own computer, in a folder readable by the owner alone, never in source control, logs or reports. They are used only to call the YouTube Data API on the owner's behalf.
  • Channel identity: channel ID, name and handle, stored in the same folder.
  • Upload records: for each upload or edit, the video ID and link, the title, tags, settings, the time, and checksums of the uploaded files. These are kept on the owner's computer as production records. They never contain sign-in tokens.

Sharing

Data received from Google is not sold, shared with or transferred to anyone, and is not used for advertising or to train AI models. It is sent only to Google's own YouTube Data API.

The ORVYQ upload tool's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube and Google terms

The tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service, and Google handles data under the Google Privacy Policy.

Retention, removal and revoking access

Tokens are kept until access is revoked. Access can be revoked at any time at myaccount.google.com/permissions (Google account security settings, under third-party connections). After revoking, the stored tokens stop working. The tool's disconnect command revokes access with Google and deletes the stored tokens and channel identity from the owner's computer. Upload records are kept as long as the owner needs them for the channel's production history and can be deleted on request.

This website

This site uses no cookies, analytics, trackers or forms. It is hosted on GitHub Pages; GitHub may log visitors' IP addresses for security, as described in the GitHub Privacy Statement.

Children

The tool is not used by or aimed at children, and it collects no information from anyone other than the channel owner.

Changes and contact

If this policy changes, the new version is posted here with a new effective date. Questions: open an issue or write through the ORVYQ channel.

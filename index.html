ORVYQ

ORVYQ is a YouTube channel (youtube.com/@orvyq) of short science films. Its series UNHEARD turns real instrument recordings, such as barometers, seismometers and satellite images, into sound and pictures.

The ORVYQ upload tool

The Google Cloud project orvyq-automation is a private tool used only by the owner of the ORVYQ channel to publish the channel's own videos. It runs on the owner's own computer. It is not offered to the public, and nobody else can sign in to it.

With the owner's permission, granted through Google's consent screen, the tool uses the YouTube Data API to:

  • upload the channel's own finished videos, private by default;
  • set each video's title, description, tags, category, language and custom thumbnail;
  • read the connected channel's name and ID, to make sure it uploads to the right channel;
  • edit the description of a video the channel has already uploaded;
  • read the channel's own aggregated YouTube Analytics (read-only) to write short performance reports on its public videos.

It does not delete videos, post comments, read comment text or identify individual viewers. Details: Privacy policy.
